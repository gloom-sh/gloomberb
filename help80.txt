gloomberb 0.14.1
Market research and portfolio tracker for the terminal

Usage
  gloomberb                    Open the terminal UI
  gloomberb <command> [args]   Run a command and print the result
  gloomberb help <command>     Show a command's usage, options, and examples

Research
  search            Search tickers and company names
  ticker            Show the full research report for one symbol
  quote             Show the latest price for one or more symbols
  compare           Compare quotes for several symbols side by side
  history           Fetch open, high, low, close, and volume over a range
  options           Fetch an options chain
  provider-search   Search instruments at the connected data providers
  correlation       Correlate two symbols' daily closes over the past year

Company data
  financials        Fetch annual revenue, profit, and EPS
  fundamentals      Fetch fundamentals and the company profile
  valuation         Fetch market cap, enterprise value, and valuation multiples
  earnings          Show upcoming and recent earnings dates
  events            Fetch dividends, splits, and earnings events
  analyst           Fetch analyst rating changes and price targets
  holders           Fetch institutional, fund, and insider holders
  insider           Fetch insider holders
  13f               Fetch institutional and fund holders
  filings           Fetch recent SEC filings
  news              Fetch market headlines, or news for one symbol

Markets
  fx                Convert a currency into your base currency
  movers            Show gainers, losers, most active, or trending stocks
  indices           Show the major US stock indices
  sectors           Show the SPDR sector ETFs
  econ              List upcoming economic calendar events
  fred              Fetch a FRED economic series (needs a Gloom Cloud sign-in)
  yield-curve       Show the latest 3M, 2Y, 10Y, and 30Y Treasury yields
  rss               Read any RSS or Atom feed as headlines

Functions
  catalog           Find market functions to run with fn or capture with shot
  fn                Run a market function and print its report
  shot              Save a desktop-style PNG of a market function

Portfolios
  notes             Read, write, or export ticker notes
  alerts            List, add, and remove price alerts
  broker            List connected broker accounts
  ibkr              List Interactive Brokers profiles
  portfolio         Show holdings and P&L, and manage manual portfolios
  watchlist         Show watchlist quotes, and add or remove symbols

Plugins
  plugins           List plugins installed from GitHub
  install           Install a plugin from GitHub
  update            Update installed plugins, or one by name
  remove            Remove an installed plugin
  plugin            Inspect, turn on or off, link, or check any plugin

App
  launch-ui         Open the terminal UI, like plain gloomberb
  api               List, inspect, call, or subscribe to plugin capabilities
  remote            Drive a running gloomberb app through its remote API
  version           Print the version, runtime, and data folder
  doctor            Check that config, cache, plugins, and capabilities load
  config            Show or change settings and keybindings
  cache             Show the size of cached market data, or clear it
  provider          List data sources and the operations each one serves
  layout            List saved layouts
  pane              List panes and templates with the plugin that owns each
  debug             Show, export, or clear the debug log of this command run
  changelog         Print the changelog or release notes in this folder
  command           List every command with its group and aliases
  coverage          Show which panes and capabilities the CLI reaches

Plugin commands
  ai                Inspect AI providers and run guarded headless AI prompts
  fear-greed        Fetch CNN Fear & Greed gauge data
  predictions       Launch the UI with Prediction Markets focused

Global options
  --json, --csv, --ndjson   Print machine-readable output instead of text
  --limit <n>               Show at most n rows
  --refresh                 Fetch fresh data instead of reading the cache
  --dry-run                 Preview config, cache, notes, alerts, plugin, and
                            remote changes without saving
  -q, --quiet               Print no results or errors in text mode, for
                            commands that print results
  --color, --no-color       Force or turn off colors (NO_COLOR=1 also turns them
                            off)
